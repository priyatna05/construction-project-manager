EARNED VALUE MANAGEMENT (EVM) IMPLEMENTATION GUIDE
================================================

1. PREREQUISITES
---------------
Yes, WBS (Work Breakdown Structure) is essential for EVM implementation because:
- Provides structured task hierarchy
- Enables accurate cost allocation
- Allows proper progress tracking
- Facilitates resource planning
- Enables precise scheduling

----------------------------

- Add task hierarchies

- Include scheduling components

2.2 New Database Tables:

tasks table modifications:
```sql
ALTER TABLE tasks ADD COLUMN (
    parent_id BIGINT UNSIGNED NULL,
    level INTEGER DEFAULT 0,
    planned_cost DECIMAL(15,2) DEFAULT 0,
    actual_cost DECIMAL(15,2) DEFAULT 0,
    planned_hours DECIMAL(10,2) DEFAULT 0,
    actual_hours DECIMAL(10,2) DEFAULT 0,
    planned_start_date DATE,
    planned_end_date DATE,
    actual_start_date DATE,
    actual_end_date DATE,
    progress DECIMAL(5,2) DEFAULT 0,
    weight DECIMAL(5,2) DEFAULT 0
);
```

Create EVM metrics table:
```sql
CREATE TABLE evm_metrics (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    project_id BIGINT UNSIGNED,
    task_id BIGINT UNSIGNED,
    calculation_date DATE,
    bac DECIMAL(15,2), -- Budget At Completion
    pv DECIMAL(15,2),  -- Planned Value
    ev DECIMAL(15,2),  -- Earned Value
    ac DECIMAL(15,2),  -- Actual Cost
    sv DECIMAL(15,2),  -- Schedule Variance
    cv DECIMAL(15,2),  -- Cost Variance
    spi DECIMAL(10,4), -- Schedule Performance Index
    cpi DECIMAL(10,4), -- Cost Performance Index
    eac DECIMAL(15,2), -- Estimate At Completion
    etc DECIMAL(15,2), -- Estimate To Complete
    vac DECIMAL(15,2), -- Variance At Completion
    tcpi DECIMAL(10,4) -- To Complete Performance Index
);
```

4. CORE EVM FORMULAS
-------------------
```php
class EVMCalculator {
    // Basic Metrics
    public function calculatePV($plannedWork, $rate) {
        return $plannedWork * $rate;
    }

    public function calculateEV($completionPercentage, $bac) {
        return ($completionPercentage / 100) * $bac;
    }

    public function calculateAC($actualHours, $rate, $additionalCosts) {
        return ($actualHours * $rate) + $additionalCosts;
    }

    // Variances
    public function calculateSV($ev, $pv) {
        return $ev - $pv;
    }

    public function calculateCV($ev, $ac) {
        return $ev - $ac;
    }

    // Performance Indices
    public function calculateSPI($ev, $pv) {
        return $pv != 0 ? $ev / $pv : 0;
    }

    public function calculateCPI($ev, $ac) {
        return $ac != 0 ? $ev / $ac : 0;
    }

    // Forecasting
    public function calculateEAC($ac, $bac, $cpi) {
        return $ac + (($bac - $ev) / $cpi);
    }

    public function calculateETC($eac, $ac) {
        return $eac - $ac;
    }
}
```
